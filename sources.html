Repository audit and verification method

Initial checkout review

  • Opened the repository root and read COORDINATION.md (it did not exist initially) before claiming work.
  • Listed root contents and checked Git status/branch.
  • Read the complete initial README.md: one heading only, # MaltaProj9 (12 bytes). It contained no healthcare claim or source to validate.
  • Found no existing site, research table, data file, site workflow, test/build configuration, or other project content.

This review does not claim that absent files were verified. It records the initial repository state.

New-site verification

  • Each published factual table row has at least one direct official-source hyperlink in its source cell.
  • Primary legal statements were compared with the enacted statute and CMS summary; state implementation details were compared with DHCS guidance and consumer notices.
  • Income guidance was checked against HealthCare.gov and IRS material; platform-specific tax treatment remains unverified.
  • Unknown personal amounts, household values, and unresolved classifications are explicitly blank or labeled unverified.
  • Internal navigation and table-source completeness are checked before publication; this is a static HTML site with no external runtime dependencies.

Verification dashboard (third parallel session)

  • A third independent session published a verification dashboard at docs/index.html, generated from machine-readable row data (data/*.json) by build_site.py with no external runtime dependency.
  • Its source register lists 73 official primary sources with the note recorded at retrieval time on 2026-10-18, and every table row carries a pinpoint citation chip (for example eCFR · 42 CFR 435.552, CA LegInfo · WIC § 14005.69, Fed. Reg. · 91 FR 33348) linking directly to the provision the row rests on.
  • It carries the verbatim text of 42 CFR §§ 435.551–435.557 and of WIC § 14005.69 in both its SB 164 and AB 2161 wordings, the California conditional-implementation safeguards at WIC § 14005.69(c)/(d)/(n), and AB 2208’s not-enacted status taken from the official legislative history.
  • Its Flagged for Review page records 23 items, including several not previously on any board here: CMS-2454-IFC was corrected on 2026-06-29; the Federal Register HTML page intermittently 404s to automated retrieval (so govinfo’s official PDF and the eCFR are used as primary); dhcs.ca.gov/workrules is a redirect; Kalshi’s P&L statement is expressly not a tax document and none of its four 1099s reports event-contract profit; and 2026 FTB mandate penalty amounts are left blank because FTB still publishes only 2025 samples.
  • Where a value could not be confirmed officially, the row renders a visible BLANK — unverified badge rather than a number. Seven categories of value are deliberately blank.
  • This session’s independent verification confirms the corrections already merged from sessions af61680c and da6d01ac: the $580 test is MAGI-based, California requires any one month per renewal period, failing the rule bars APTC/PTC, and DHCS’s $15,560 copayment figure matches no published poverty guideline.
